## Background

I got into Linux by running it as my only desktop, then kept going: theming and
ricing Hyprland, writing shell and Python to automate the boring parts,
self-hosting services on a home server, and packaging the whole setup so a
fresh install can be rebuilt from a repo instead of memory.

More recently I've been working upstream in the Omarchy plugin ecosystem and on
Android — contributing fixes to launcher and VPN plugins, wiring AI coding
agents into app tooling, and building native preview builds of a game engine
player. I like small, well-understood tools that do one job and don't need a
manual.

## Open Source

I build in the open and send fixes upstream. Selected contributions:

- [omamail](https://github.com/huacnlee/omamail) — merged fix for helper script paths in scoped Omarchy 4.x plugins
- [omarchy](https://github.com/omacom/omarchy) — Keychron RGB handler in the theme keyboard pipeline
- [omarchy-proton-vpn](https://github.com/iamfitsum/omarchy-proton-vpn) — keyring fixes that keep Proton signed in across reboots
- [omalauncher](https://github.com/SimonSchubert/omalauncher) — Hermes Agent support, installed via its own installer
- [omarchy-proton-drive](https://github.com/placq/omarchy-proton-drive) — selectable proton-sdk provider reusing the official CLI session

Issues, PRs, and feedback are always welcome.
